# Shared placeholder assets

Fallback assets used when a design supplies no package of its own. Like the per-package assets in
`mode/*/packages/*/assets/`, these are placeholder graphics created for this plugin - a coloured
rectangle with the asset key as a label - and carry no third-party artwork.

Licence: GPL v3 or later, the same as the rest of the plugin.

See any `mode/*/packages/*/LICENSE.txt` for the background and for what a replacement has to
satisfy.
